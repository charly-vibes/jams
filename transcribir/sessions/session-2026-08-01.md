# Transcribir Development Session — 2026-08-01

## Overview

Created a browser-based audio transcription tool using Whisper via transformers.js. Runs entirely client-side — no server, no uploads. Designed for phone use as a PWA.

## Origin

This is a port of the `transcribe` bash script from the `canticos` repo (`bin/transcribe`), which uses `ffmpeg` + `whisper-cli` (GGML) locally. The browser version replaces:

| Component | Browser equivalent |
|-----------|-------------------|
| `ffmpeg` audio conversion | `AudioContext.decodeAudioData()` + `OfflineAudioContext` resampling |
| `whisper-cli` + GGML model | Transformers.js pipeline (`Xenova/whisper-*`) |
| Local `.txt` output | DOM display + copy/download |
| File from disk | `<input type="file">` or `MediaRecorder` mic capture |

### Key technical decisions

1. **Model caching**: Transformers.js caches ONNX weights in IndexedDB automatically. Second load is instant.

2. **Audio resampling**: `OfflineAudioContext` at target sample rate creates a new buffer and renders through. Simple, reliable, no external dependency.

3. **Mic recording**: `MediaRecorder` with opus-in-webm (preferred) or fallback to ogg/mp4. Chunks collected every 250ms, assembled into a Blob on stop, then decoded like a file.

4. **Chunked processing**: Audio is split into 30-second windows and processed sequentially. Memory usage is constant regardless of total duration. Progress shows "fragmento N de M".

5. **Timestamped output**: Whisper returns `chunks` with timestamps. They are accumulated with offset correction and rendered as SRT or VTT, falling back to plain text if unavailable.

6. **Stereo handling**: All channels are averaged to mono (instead of taking channel 0), fixing silent transcription on devices that record muted channel 0.

### Edge cases handled

- Tab switch during recording -> visibilitychange listener stops mic
- Double-tap record -> button disabled during getUserMedia negotiation
- Long audio (>25 min) -> warning banner with duration estimate
- No speech detected -> warning message (not error)
- AudioContext leak -> try/finally ensures close()
- Firefox recording -> Ogg/Opus mimeType fallback
- Very short recordings -> empty transcription, no-speech warning

## Design rationale

- **Dark theme** (`#0f0f1a`): better for phones in low light, easier on eyes during long transcription sessions
- **Big touch targets**: buttons are full-width (min 44px), upload zone has min-height for fat-finger tapping
- **Single-column layout**: works on any phone width without horizontal scroll
- **Progress overlay**: model download shows percentage, chunking shows fragment N/M
- **Format selector**: TXT / SRT / VTT lets user choose between plain text and timestamped output
- **Minimal permissions**: only requests mic access when user taps "record", not on page load

## Post-Review Changes (Rule of 5)

After a Rule of 5 review, the following issues were addressed:

### HIGH priority
- **Chunked processing for long audio**: Audio split into 30s windows, processed sequentially. Memory constant regardless of duration.
- **Timestamped export**: New SRT / VTT output format selector accumulates Whisper's timestamped chunks with offset correction.
- **Output format selector**: TXT/SRT/VTT dropdown in output header.

### MEDIUM priority
- **AudioContext leak fix**: `audioCtx.close()` runs in `finally` block even on decode error.
- **Stereo-to-mono averaging**: All channels averaged instead of channel 0 only.
- **Duration display**: Audio duration shown in file info badge.
- **Recording guard**: Button disabled during getUserMedia negotiation.
- **Visibility change handler**: Recording stops automatically when tab hidden.
- **Firefox Ogg/Opus support**: Added to mimeType fallback chain.
- **isTranscribing guard**: Transcription blocked during active run; tab switching disabled.

### LOW priority
- **Long audio warning banner**: Shown when decoded PCM exceeds ~100 MB (~25 min).
- **Download filename**: Extension stripped properly, colons replaced for filesystem compatibility.
- **Button re-enabled on failure**: User can retry without reloading.
