#+TITLE: jams-8be.7 — Voice changes: one question at a time (fixture design)
#+DATE: 2026-11-02

* Design

**Pure layer** — new =listar/voice-resolution.mjs= (no storage/DOM):
- =analyzeVoiceTranscript(transcript, workspaceSnapshot, { collectionId })= →
  scopes to non-archived items in the collection (or the whole workspace),
  reuses =analyze()= over a list-shaped context; =commandLike= = any candidate
  that is not a plain add (A05 repair, A06 removal, repeat adds).
- =createVoiceSession(voice, { operationId, audioId })= → frozen session holding
  snapshot, scope label (=Cambios en Compras= / =todas tus listas=) and answers.
- =sessionStep(session)= → the FIRST pending question only, or =null= when fully
  resolved: =target= (duplicate labels; choices = label · colección · cantidad ·
  marca · paquete; identical undistinguished labels get =Leche · entrada 1=
  aliases), =disposition= (=¿Archivar o quitar de la lista?=; detach only when a
  membership exists; unassigned items explain only archive is available),
  =repair= (A05 =leche no yogur= → =Agregar leche= / =Agregar yogur=),
  =repeat-add= (add-distinct vs increment-existing), =blocked= (unsupported /
  set / attribute candidates → only =Quitar de esta captura=, never an add).
- =answerStep= / =excludeCandidate= → new immutable session;
  =sessionActions(session)= → ={ ok, actions }= with kinds =add | archive |
  detach | increment= — NEVER destructive =remove=; unresolved → =ok: false=.
- =isSessionStale(session, snapshot)= → revision moved (A18 fresh review).

**Persistence** — =workspace.mjs= =commitVoiceActions(actions, operationId,
expectedRevision)=: fresh-snapshot preconditions (detach verifies the expected
membership; stale membership rejects for fresh review, 0 writes), operations-store
replay (identical retry returns the original outcome), one guarded transaction
for workspace-owned targets; legacy-owned archive delegates after a guarded
revision bump (existing bump-first precedent). Archive preserves ID/membership/
source/attributes; detach writes one membership record, item stays in Sin lista.

**UI** — =script.js= / =index.html=: dictation whose analysis is command-like
opens the voice card instead of the add draft: one select per question, scope
line, =Guardar N cambios= when resolved, =Cancelar= writes nothing; single-action
commits get an undoable receipt (archive/membership/quantity inverses exist);
stale commit or changed membership re-runs analysis (renewed review). Destination
change re-scopes mid-review (renewed analysis); view navigation never touches
scope. Shell gains =voice-resolution.mjs= → cache v9.

* Out of slice

- Batch (multi-action) undo receipt: single-action voice commits are undoable;
  multi-action commits show a plain receipt — follow-up ticket.
- =set= / typed-attribute voice candidates stay =blocked= (exclude); the typed
  editor flow (A18 full editor reconfirmation) is jams-8be.12 browser territory.
